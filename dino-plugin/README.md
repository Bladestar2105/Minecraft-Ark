# ARK dinos

Small server plugin for Paper **26.3 build 236**, Java **25**. Native Sniffers and Ravagers remain the gameplay entities and mounts. The optional BetterModel/PacketEvents/GeyserModelEngine presentation stack attaches the six custom models when available; without it, native taming and riding remain usable. Geyser clients use their normal interact, jump and sneak controls; Bedrock/PS5 rendering and device input still need a real client test.

In the `ark` Survival world, interact with an `ark_dino` using one torchflower seed in the main hand. One seed is consumed and your UUID is saved on the existing entity. Sneak and interact again, with any main-hand item, to toggle stay/follow. Other players cannot change ownership, command or leash the pet. Creative players cannot acquire or command Survival pets. Wild Ravagers retain their normal attacks.

With an empty main hand, interact with your tamed Sniffer or Ravager to ride it. Use normal forward/backward/strafe controls and look to steer; sneak to dismount. Only its Survival owner can mount an unoccupied pet in an allowed world. Sneak+interact while on foot still toggles stay/follow. Riding pauses follow pathfinding and preserves the saved stay setting. Ground movement has a fixed conservative speed, keeps native gravity and collisions, and stops before unloaded chunks. Ground species cannot fly. There is no saddle or extra control setting. Logout, death, mode/world changes, pet unloading and plugin shutdown end control and remove passengers.

The Pteranodon alone can fly: jump takes off and ascends, look and use directional controls to steer, and look down while moving forward to descend and land. Releasing controls hovers. Ascent stops at 48 blocks above takeoff or below the world ceiling, whichever is lower. Native collisions remain active; rider headroom is reserved, water ends flight, and an unloaded destination stops all velocity without loading chunks. Sneak dismounts; the mount descends under control. Flight exits give the former rider and mount bounded slow falling long enough to reach the world's minimum height, including when unload or shutdown interrupts landing. Gravity is restored on landing, unload, death, disable and stale flight-state recovery; fall-distance resets apply only during controlled flight/landing. Normal damage and void damage still apply.

To enable custom dinosaurs only in selected worlds while keeping other pets native, include the allowed worlds in `survival-worlds` and list only model worlds in `prototype-worlds`:

```yaml
survival-worlds: [ark, custom_dinos]
prototype-worlds: [custom_dinos]
```

`prototype-worlds` limits new species identification/migration, model attachment and Pteranodon flight. Outside it, existing ownership, tame/stay/follow and native ground riding continue, and saved species cannot enable flight. Omit the setting to use `survival-worlds`; set `[]` to disable prototype features everywhere. A persisted active-flight marker still restores gravity on load for safety. Removing an allowlist entry does not delete its world or entities.

Six species persist as `arkdinos:species`: `triceratops`, `stegosaurus`, `trex`, `brachiosaurus`, `pteranodon`, `velociraptor`. Exact legacy habitat tags `ark_renewal_habitat_01_dino_0` through habitat 12, slot 1, map those species in that repeating order: four entities per species across the 24 tags. T-Rex and Velociraptor use Ravagers; the other four use Sniffers. Compatible saved species win over habitat tags. Conflicting or incompatible tags use a logged native-type default (Triceratops or T-Rex), as do untagged legacy owned dinos. Ordinary untagged mobs remain unchanged. Migration updates PDC/model attachment on the existing entity, preserving UUID, health, position, ownership and stay state, without respawning or teleporting it. Tagged wild dinos also receive models on enable, entity load and supported spawn events.

Owned dinos are passive, including Ravagers' damage and target selection. They follow their online Survival owner in the same world, between 3 and 48 blocks away, using native pathfinding. They stop when staying, the owner leaves, changes world or enters Creative, or goes beyond 48 blocks. Come back near a pet to resume following. Pets do not teleport, load chunks or cross portals/worlds. Native pathfinding cannot guarantee passage through fences, cliffs or deep water; stay pauses AI but does not pin an entity against pushing or water currents.

The plugin creates no entities and never respawns a dead or unloaded pet. Ownership and stay state persist through normal world saves/restarts as entity PDC: `arkdinos:owner` (UUID string), `arkdinos:stay` (byte), `arkdinos:species` (string). `arkdinos:flight` is a temporary persisted recovery marker, removed when gravity is restored. Only currently loaded pets are kept in memory; their paths update once per second. Load restores their controller. Habitat datapacks must not teleport `ark_dino_tamed` back to their home, or respawn replacement groups when pets leave.

Sniffers use a Brain rather than ordinary goal selectors. A small Minecraft 26.3 adapter clears their native Brain behaviors once on tame/load, allowing Paper's Pathfinder to control them. This also replaces natural sniffing/digging behavior on owned Sniffers. The adapter must be checked after Minecraft upgrades; failure stops a pet safely and refuses new Sniffer taming without consuming the seed. Untamed Sniffers retain their normal AI. Healing is omitted.

## Build

Run `rtk proxy bash dino-plugin/build.sh` from the repository root with JDK 25 in `JAVA_HOME`, or use the local verified JDK at `dino-plugin/.tools/jdk-25.0.5+8/Contents/Home`. Build dependencies are downloaded with fixed SHA-256 checksums and kept outside Git. Cloudflare DoH is used for these downloads because the current VPN DNS was unreachable; it changes no system DNS setting.

Output: `dino-plugin/build/ArkDinos-1.1.0.jar`. Copy that single JAR to the server's `plugins/` directory and restart normally. The generated `plugins/ArkDinos/config.yml` allows only `ark`; add other Survival worlds explicitly if wanted. Do not hot-reload plugins.

The build runs dependency-free checks for ownership, Survival restrictions, food consumption, stay/follow, mounting restrictions, directional movement, all 24 legacy species tags, deterministic migration, flight math and passenger packet ordering. These checks do not replace the native runtime checks below.

`rtk proxy node dino-plugin/riding-runtime-test.mjs` creates a fresh loopback-only Paper 26.3/236 fixture under `dino-plugin/build/riding-smoke-*`, compiles a test-only fixture plugin and stops its server afterward. It reads cached Paper bootstrap/libraries from `artifacts/renewal-20261103/` without opening that historical server's worlds. Set `DINO_PAPER_JAR` and `DINO_PAPER_CACHE` for another matching local cache. It uses direct Java protocol777 test clients and no Node dependencies. The report is `dino-plugin/build/riding-runtime-report.json`. Chunk unloading is a fixture-dispatched `EntitiesUnloadEvent`; official Java, Bedrock/PS5 clients, actual ridden chunk unloading and difficult terrain still need playtesting.

Verified on 2026-11-07: all eight riding smoke checks passed, including both native species mounting through actual interaction packets, forward input moving each about 4.4 blocks per second on flat ground, unchanged height, sneak dismount, ownership/item/mode/passenger denial, preserved stay, mode/world/logout/death cleanup, the unload-event fixture and native plugin disable. Follow paths remained stopped while mounted; no chunks were force-loaded and no ArkDinos errors occurred. Native collision pushes after dismount remain normal physics.

`rtk proxy node dino-plugin/gameplay-runtime-test.mjs` creates a separate fresh Paper world under `dino-plugin/build/gameplay-smoke-*`. It checks all 24 migrations and native identity/state invariants, compatible PDC and conflict handling, actual input-packet takeoff/hover/pitch descent/landing/remount, owner/mode restrictions, flight exits and gravity recovery, the altitude cap, rider head obstruction, water, unloaded-destination XYZ stopping, and a clean server restart. `build/gameplay-runtime-report.json` includes actual server position/NoGravity samples in `flightSamples` for takeoff, hover, steering/descent and landing. Chunk lifecycle and the unloaded-destination guard use test-only native fixtures; this does not substitute for actual distant chunk unloading or Bedrock/PS5 device QA. Both isolated harnesses stop their own server processes afterward. To repeat gameplay with the exact optional stack and all six assets, run `rtk proxy env DINO_MODEL_STACK=1 node dino-plugin/gameplay-runtime-test.mjs`; it uses the cached Paper 26.3/241 + BetterModel 3.6.0 + PacketEvents 2.14.0 + GeyserModelEngine 1.0.9 + Geyser b1284 stack in a fresh world, checks model trackers and actual flight animation selection, and writes `build/gameplay-model-runtime-report.json`. It reads the local spike cache but never opens its world.

The repository's loopback preview has an automated real-client harness: `rtk proxy node dino-plugin/runtime-test.mjs`, followed by a parent-controlled server restart and `rtk proxy node dino-plugin/runtime-test.mjs --verify-persistence`. Its guard checks `artifacts/renewal-20261103/server/server.properties`; it uses local RCON 25585, ViaProxy 25578 and separate `RenewalDino`/`RenewalDinoB` profiles. It creates temporary fixtures at X/Z 100–145, Y 200–210. `--resume` reuses passed baseline checks and existing fixtures after a harness interruption. `--cleanup` removes those fixtures and keeps the result reports. The current Mineflayer version requires `useOn()` for sneak interactions because `activateEntity()` hardcodes a non-sneaking click.

## Native runtime checks

On an isolated Paper 26.3/236 test server, use two ordinary non-OP players and a safe flat test area in `ark`. Keep pets away from habitat respawn functions during the test.

1. Confirm `version ArkDinos` and no plugin errors in the log. Summon one tagged Sniffer and one tagged Ravager with `Tags:["ark_dino","ark_dino_wild"]` and `PersistenceRequired:1b`. Also keep one untagged control mob.
2. Give player A two torchflower seeds. Interact with each tagged mob in Survival: ownership must equal A's UUID, each interaction removes exactly one seed, and `ark_dino_tamed` replaces `ark_dino_wild`. Untagged mobs must remain unowned. Try in Creative first: no owner and no seed consumption.
3. Player B tries to tame, sneak-command and leash A's pets: their owner and stay state must not change and B's seeds must remain. A sneaks and interacts: `arkdinos:stay` changes between `1b` and `0b`, without consuming items.
4. A walks 10 blocks on flat ground without holding seeds. Each following pet must approach; in stay mode it must remain nearby when A moves. Test owner logout, Creative, changing to `ark_creative`, and returning near the pet. No chunk should be force-loaded and no cross-world pet should appear.
5. In Survival without resistance, A and B approach the owned Ravager and provoke it. Health must remain unchanged by that Ravager, including roar, and a nearby owned wolf must not be targeted. A separate wild Ravager must still attack; test it in a separate enclosed area.
6. Save and restart the server. Query the same entity UUIDs: owner and stay bytes must remain, total entity count must not increase, and the owned Ravager must remain passive after provocation. Unload and reload a pet's chunk and repeat follow/stay.
7. Empty A's main hand, interact with each pet and steer in all four directions. Confirm no follow path runs while riding, diagonal travel is not faster, no flight occurs for ground species even with jump, and sneak dismounts without changing stay. B, Creative A, held items and wild/occupied dinos must refuse mounting. Repeat logout, death, world/mode change, chunk unload and plugin shutdown while mounted; riders and horizontal control must clear. Attempt to add another entity as a passenger: it must be rejected.

Useful console/RCON probes (commands omit the leading slash):

```mcfunction
version ArkDinos
execute in minecraft:overworld run data get entity @e[type=minecraft:sniffer,tag=ark_dino_tamed,limit=1] BukkitValues
execute in minecraft:overworld run data get entity @e[type=minecraft:ravager,tag=ark_dino_tamed,limit=1] BukkitValues
execute in minecraft:overworld run data get entity @e[type=minecraft:ravager,tag=ark_dino_tamed,limit=1] UUID
execute in minecraft:overworld run data get entity @e[type=minecraft:ravager,tag=ark_dino_tamed,limit=1] Tags
execute in minecraft:overworld if entity @e[tag=ark_dino_tamed]
execute in minecraft:overworld run forceload query
save-all flush
```
