# Original dinosaur assets

Eight original CC0 models: T-Rex, Triceratops, Stegosaurus, Brachiosaurus, Velociraptor, Pteranodon, a Jurassic Park inspired Dilophosaurus and a 24-block Mosasaurus. Dilophosaurus has two head crests, an articulated red/yellow neck fan, an olive striped body, three finger claws and a separate spit pose. Triceratops has two preserved brow horns and a larger central nasal horn, checked as a separate silhouette from front and side. The 2026-11-08 refinement adds tapered anatomy, chamfered body masses, species-specific heads and connected Pteranodon membranes. Editable Blockbench 5 free-format models include embedded 64×64 skin atlases with scale edges, mottling, belly folds, horn streaks and leather veins. No third-party dinosaur geometry or textures.

Run from the repository root with Python 3 and only its standard library:

```sh
rtk proxy python3 dino-models/build_models.py
rtk proxy python3 dino-models/verify_exports.py
rtk proxy python3 dino-models/verify_animated_bounds.py
rtk proxy python3 dino-models/verify_gait.py
rtk proxy python3 dino-models/verify_portability.py
rtk proxy python3 dino-models/test_previews.py
rtk proxy python3 dino-models/test_model_poses.py
rtk proxy python3 dino-models/test_mosasaurus.py
```

The public source is text-only: `models/<id>/` contains `<id>.bbmodel`, `<id>.geo.json`, `<id>.animation.json`, `config.json` and `design.json`, alongside the generation/verification scripts, this README and the CC0 license. Textures are embedded in each BBModel. `build_models.py` deterministically regenerates the model exports and standalone PNGs when needed. `verify_exports.py` validates embedded PNG dimensions, chunk checksums, opacity, sampled material variation, UV bounds and exact source/Bedrock face rectangles; an optional external PNG is compared when present. It retains the six calibrated back heights; the added Raptor jaw joint articulates existing geometry. Dilophosaurus has a calibrated back height of 1.191365 blocks. Asset verifiers do not depend on previews, private spike files, absolute paths or separately published textures.

The public installer decodes the embedded textures, prepares both engines and serves the generated Java pack automatically at `/resources/dinos.zip` through the player portal. Configure the public portal URL with `python3 scripts/setup.py --portal-url https://portal.example.org/` and enable required resource packs; the installer sets the Java pack URL and handles the Bedrock pack path. The all-in-one installation needs no separate manual HTTP service. BetterModel 3.6.0 consumes BBModels from `plugins/BetterModel/models/` and generates `plugins/BetterModel/build.zip` for that route.

GeyserModelEngine 1.0.9 input: copy each model's geometry, animation, texture and `config.json` into `plugins/Geyser-Spigot/extensions/geysermodelengineextension/input/<id>/`. For a text-only distribution, decode the model's `textures[0].source` data URI into `<id>.png`; the installer extracts the exact embedded bytes. The config binds that texture basename to all bones. **Animation input keys are short names** (`idle`, `walk`, `flap`, `glide`, `attack`, `spit`, `swim`): this bridge adds `animation.<id>.` itself and uses the short keys for BetterModel synchronization. Fully prefixed input keys silently produce incompatible runtime aliases.

`verify_portability.py` copies only the public text asset files to a fresh temporary directory and runs export, animated-bounds and gait verification there, without generating external PNGs. It also proves a mismatched optional PNG is rejected.

The seven land/flight models have idle/walk loops; Pteranodon also has flap/glide, with a culling box height 4 / offsetY 1.3 covering full wing travel. Pteranodon's two outer-wing bones fold the membranes vertically beside the body in both ground animations; flap/glide explicitly open both joints. Folded span is 45 model units versus 131 while gliding. T-Rex has larger curved ivory toe claws and two hooked finger claws on each hand. Brachiosaurus's tail tip reaches within 0.12 model units of the floor without changing its back or feet. `test_model_poses.py` checks transformed geometry, claw size, folding clearance and open flight poses rather than names alone.

Carnivores have exposed pointed upper/lower tooth rows; Triceratops and Stegosaurus have short, narrow cheek teeth set inside their jaw edges behind toothless beaks, hidden in the closed mouth. Brachiosaurus has four slender recessed spoon/peg teeth per jaw. Pteranodon keeps its toothless beak. Independent oriented-box tests check exposed tooth tips and flesh contact between the posed jaw and skull throughout mouth opening.

Each model also has a finite `attack` clip: T-Rex bites and moves its short arms, Raptor/Dilophosaurus bite and rake their claws, Triceratops thrusts its horns, Stegosaurus swings its tail, Brachiosaurus stomps one foreleg, Pteranodon jabs its beak, and Mosasaurus lunges with its jaw. Dilophosaurus additionally unfolds its fan and opens its jaw for `spit`, then folds it again. The exported Bedrock clips use `loop: false`; the Java adapter uses `PLAY_ONCE` at priority 200 with untouched bone branches excluded. Main phase objects continue without restart, and combat clips never animate the body or saddle root.

Triceratops horns, all Stegosaurus plates and tail spikes, Pteranodon’s crest, and Dilophosaurus’s twin crests and folding frill also have `growth_baby`, `growth_juvenile` and `growth_adult` loops. They scale dedicated `growth_` child bones at 20/55/100% for horns, crests and spikes, or 30/65/100% for plates and frill. Root pivots keep growing details attached; body proportions, locomotion and combat pose curves stay unchanged. The frill growth bones sit between the existing attack roots and rotating ribs, so growth and unfolding can play together. `test_growth_details.py` verifies coverage, hierarchy, stage scaling and adult source geometry and motion. On Java, detail scales share their animated parent's phase clock; a separate stage flag preserves the Bedrock growth animation.

Walking has a longer planted stance, a lifted return and per-leg vertical compensation. Bipeds alternate legs; quadrupeds use four phases. `walk_stride_blocks` in each design records the mean foot's Z travel during the 60% planted stance divided by that stance fraction as geometry metadata. Land walks use an incremental clock from ground speed, clamped to 0.35–1.8 cycles per second; the species ground targets of 1–2 blocks per second walking and 2–7 sprinting produce a bounded 0.35–1.75 cycles per second on Java and Bedrock. This avoids rapid cycling with short voxel legs and phase jumps as young dinosaurs grow. Walk tracks retain their exact original linear pose path, resampled at 50 ms intervals so BetterModel receives small target steps despite whole-tick display interpolation. The existing fast mount travel can still outpace the short planted foot sweep. `test_model_poses.py` samples the clock at both mount speeds, three growth scales and 30/60 frames per second. `verify_gait.py` independently samples 101 instants per leg, requiring a planted stance, visible swing clearance and at most 0.2 model units of floor penetration between keyframes. Independent corner transforms sample all animation channels at keyframes and intermediate rotations at no more than 0.25 degrees; the seven land/flight models are grounded exactly in rest pose. No inverse kinematics or terrain adaptation is provided.

`render_previews.py` uses embedded PNG pixels and each face's UV rectangle, with a per-pixel depth buffer for intersecting details such as eyes. It evaluates the actual idle bone pose by default, including nested folding joints. Run it with Python 3 and `rsvg-convert` installed to regenerate the eight PNG/SVG previews, idle/attack gallery, six open-mouth tooth closeups, contact sheet, Dilophosaurus folded/open/attack poses, T-Rex feet/hands, Brachiosaurus tail side view Pteranodon idle/walk/flap/glide poses with its seated-player reference, Stegosaurus plate details, and Mosasaurus swimming/bite/size comparisons. `test_previews.py` checks that changing UVs, embedded pixels or bone poses changes the rendered image. These orthographic asset previews are not screenshots from Minecraft.

The actual BetterModel 3.6.0/GeyserModelEngine 1.0.9 packs and runtime evidence are local under `output/dino-assets-runtime-20261107/`. `verify_compiled.py` reconstructs every compiled Java corner through vanilla item-display transforms and compares it with the editable source (tolerance 0.001 model units); it also checks UVs, exact textures and all generated Bedrock references. This catches arbitrary-angle errors that an axis-aligned spike or comparing two exporters cannot catch.

No real Minecraft renderer, Bedrock login, PS5 or Switch was available. Headless protocol/resource-pack acknowledgments and HTTP checks do not prove visual rendering or client resource-pack application. Mount controls, collision, combat and server deployment belong to the gameplay/adapter integration.

Mosasaurus is a wild aquatic model: four articulated flippers, a powerful tapered tail with a vertical fluke, dark bluegray mottling, pale underside and exposed upper/lower tooth rows. Its phases are `idle`, `swim` and finite `attack`. The native Dolphin controller owns SCALE 4 (about 3.6 × 2.4 blocks); the visible model stays at scale 1 and has no custom seat. The 24-block head/tail and broad flippers exceed the native collision box, so the aquatic controller must enforce deep-water clearance. Model forward is -Z; the adult mouth anchor is [0, 1.0625, -9.4375] blocks relative to native feet. The swim clock adds `query.life_time * 0.15` to its six-block distance cycle so pure vertical movement still animates on Bedrock.

Pteranodon keeps its fixed calibrated back while its crest is reangled ahead of the rider; independently posed crest cubes clear the measured 0.6 × 1.8 block native player box with an 0.08-block margin across every phase. Flap and glide tuck both hindlegs back; ground feet and folded wings retain their existing poses. Stegosaurus has alternating small neck/tail plates attached to the corresponding moving bones and large back plates beside the rider, with the same independent saddle-clearance checks.

Each dinosaur also has an empty `name_anchor` above its moving head. It renders no cubes. ArkDinos positions its ordinary native TextDisplay there, allowing consistent custom names without the BetterModel per-viewer name-label cache. `test_nametags.py` checks all eight source and Bedrock anchors.
