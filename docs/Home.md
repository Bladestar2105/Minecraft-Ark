# Minecraft ARK – Wiki

Minecraft ARK ist eine vorbereitete Survival-Abenteuerwelt für Java 26.3 und
Bedrock über Geyser/Floodgate. Ein eigener Server wird benötigt.

1. [Welt herunterladen](World-Download.md) und Prüfsummen prüfen.
2. [Installieren](Installation.md), eigene Geheimnisse erzeugen und den Server starten.
3. [Spielen](Playing.md): Atlas, Quests, Grundstücke, Dinos und Kreativtor.
4. [Administrieren](Administration.md), Sicherungen und Passwortwechsel.
5. [Probleme lösen](Troubleshooting.md) oder [Quellcode bauen](Development.md).
