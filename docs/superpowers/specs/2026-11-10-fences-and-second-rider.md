# Open habitats and a second rider

## Confirmed context

The user confirmed that the original complaints occurred on ArkDinos 1.1.0 in
the live survival world, after the test-world restriction was removed. A live
read through the authorized administration portal also reports 1.1.0 and both
world lists containing `ark`. The old binary release is not an explanation of
these reported incidents.

The user authorizes removal of the original dinosaur enclosure fences and
implementation of a second rider. Existing player builds, animals, ownership
and world files must be retained.

## Habitat migration

Use the original twelve habitat locations, verified against the live atlas and
generation markers. Remove only the perimeter fence/gate layer generated by
the historical world builder. Preserve the two northern lamp posts and all
other blocks. Capture actual block states before applying bounded, conditional
changes; include a repeatable dry-run and an undo that does not overwrite later
player changes. Load only the necessary maintenance chunks and release only
the tickets introduced by this operation. Do not run the world-building pack.

## Second seat

Initial supported species: adult T-Rex, Triceratops, Stegosaurus and
Brachiosaurus. Other species retain one seat. The first rider remains the sole
driver and dinosaur attacker; no automatic promotion occurs when they leave.
The second rider uses the same owner/public permission and a separate,
nonpersistent invisible seat 1.2 blocks behind the driver, at the same actual
foot height. Preserve independent camera orientation.

Native probing established that two direct passengers and a child marker
overlap. The separate marker must follow native position updates without
per-tick player teleports. Reject the second seat safely if the pinned native
API is unavailable. Its Bedrock seat height uses a separately verified offset;
the optional model adapter synchronizes its display clock with the visible
dinosaur. The native seat remains usable without the model plugin.

Guest dismount affects only the guest. Driver exit, death, permission removal,
world/teleport changes, unload and shutdown clean up the appropriate riders
and seat without transferring ownership or loading remote chunks. Protect both
riders from their dinosaur's attacks and reserve the second rider's swept
volume during movement, rotation and swimming.

## Verification and delivery

Exercise the failure cases before correction, then run native two-client tests
for position, movement, camera, authority, revocation, obstruction, swimming and
lifecycle cleanup. Test model packet synchronization and Bedrock seat metadata
separately; do not claim real-client visual acceptance from these probes.
Keep the new plugin changes on the existing draft PR. The authorized live
world operation is fence removal; do not replace the live plugin with an
unreviewed second-seat build or replace its world archive.
